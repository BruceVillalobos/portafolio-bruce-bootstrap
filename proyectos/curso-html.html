Curso de HTML básico

Diseño y estructura de páginas web

Un curso introductorio para quienes quieren dar sus primeros pasos en el desarrollo web con HTML5.

Inscribirme Ver temario
HTML5

Duración: 6 semanas

Modalidad virtual, nivel inicial

¿De qué trata el curso?

Duración

6 semanas con 2 sesiones semanales de una hora.

Modalidad

Clases virtuales en vivo y ejercicios para practicar en casa.

Nivel

Inicial. No necesitas conocimientos previos de programación.

Material

Apuntes, ejemplos de código y proyectos guiados paso a paso.

Temario del curso

Módulo 1: Introducción

  • ¿Qué es HTML y para qué sirve?
  • Estructura básica de un documento HTML5.
  • Etiquetas, atributos y anidamiento.

Módulo 2: Texto y enlaces

  • Encabezados, párrafos y listas.
  • Enlaces internos y externos.
  • Imágenes y atributo alt.

Módulo 3: Estructura semántica

  • Etiquetas header, nav, main, section y footer.
  • Organización del contenido.
  • Accesibilidad básica.

Módulo 4: Formularios

  • Campos de entrada, etiquetas y botones.
  • Validación básica con HTML.
  • Construcción de una página completa.

Beneficios de estudiar conmigo

Aprendizaje práctico

Cada clase termina con un ejercicio aplicado a un caso real.

A tu ritmo

Las grabaciones quedan disponibles para repasar cuando quieras.

Buenas prácticas

Desde el inicio aprenderás HTML semántico y accesible.
